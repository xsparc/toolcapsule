# Security policy

ToolCapsule is an early MVP, not an independently audited multi-tenant sandbox.
Read the [security boundary](docs/security.md) before integrating it.

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/xsparc/toolcapsule/security/advisories/new).
Include a minimal synthetic reproduction and affected revision. Do not include
real secrets, private packages, machine identifiers, or customer data.

The initial development line is 0.1.x. No response-time or support-lifetime
commitment is made. Runtime updates require capability and replay regression
checks; dependency advisory checks are part of ongoing stewardship.
